O backup inclui produtos e vendas. Salve o arquivo em um local seguro e importe-o quando precisar recuperar seus registros.

Restaurar backup

Importar um backup substitui os produtos e vendas atuais deste navegador. Faça um backup antes. Não envie arquivos de backup para pessoas desconhecidas, pois podem conter informações comerciais.

Sobre os dados

Esta versão guarda os dados no armazenamento local do navegador. Eles não são enviados a um servidor e não sincronizam automaticamente entre aparelhos. Limpar os dados do navegador pode apagá-los.
